# Develop a Memory Game

Build a memory game with a shuffled grid of symbol cards. Players flip two cards per turn; matching pairs remain face up, and non-matching cards flip back after a short delay. The goal is to match all pairs.

Requirements: use a 4x4, 6x6, or 8x8 grid; support one or two players; shuffle cards; flip cards on click; compare pairs; and show a win state when every pair is matched.
